# Azure Security Foundations & Identity Governance Lab

An implementation-focused lab documenting Zero Trust identity architectures, cloud boundary controls, data governance, and threat detection fundamentals across Microsoft Entra ID, Microsoft Purview, and Microsoft Defender.

---

## 🎯 Focus Areas & Skills Acquired
- **Identity & Access Management (IAM):** Zero Trust access models, Conditional Access policy design, and administrative boundary controls via Microsoft Entra ID.
- **Data Governance & AI Compliance:** Sensitive data discovery, classification labeling, and Data Loss Prevention (DLP) guardrails using Microsoft Purview and Priva.
- **Cloud Perimeter Defense:** Ingress/egress traffic inspection, network security group (NSG) segmentation, and workload baseline security.
